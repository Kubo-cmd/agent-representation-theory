# Security Policy

## Supported versions

The default branch is the supported development line. No stable release has been declared.

## Reporting

Report suspected vulnerabilities privately through the repository host's security-reporting feature. Do not open a public issue for an unpatched vulnerability and do not include live credentials, personal data, or exploit traffic.

Include the affected commit, a minimal reproduction, impact, and any proposed mitigation. Reports are validated against the exact cited revision before a fix is prepared.

## Scope

This project performs local numerical computation and has no network, credential, subprocess, or persistence authority. A future change that adds any such capability requires explicit documentation, tests, and review.
